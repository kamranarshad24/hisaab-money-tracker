# Hisaab – setup

1. **Host the folder** (any static host, e.g. GitHub Pages / Cloudflare Pages). Open the link in Chrome on the Redmi → menu → *Install app* / *Add to Home screen*.
   Your data is stored only on the phone; the hosted files contain no personal data.
2. **Import notes**: Settings → paste your notepad → review (yellow rows need a check) → Add selected.
3. **Balance check**: Accounts → *Check balances now*, at the end of the day, weekly (HBL, Easypaisa, JazzCash, Cash).
   The first check is only a starting point; unlogged money shows from the second check onward.
4. **Reminders**: Settings → download the two calendar files and open them (Google Calendar adds a repeating alarm).
5. **Google Sheet backup** (optional): new Google Sheet → Extensions → Apps Script → paste `apps-script.gs` →
   Deploy → Web app (Execute as: Me, Access: Anyone) → copy the URL into Settings → Google Sheet backup.
